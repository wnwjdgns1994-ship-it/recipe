밀프랩 키친 V5.1 — 설치형 웹앱(PWA) 배포 파일
이 ZIP은 APK가 아닙니다. 압축 해제한 파일을 HTTPS 정적 웹 호스팅에 올려야 홈 화면에 설치할 수 있습니다. 앱 데이터는 브라우저 로컬 저장소에 남고 서버에는 전송하지 않습니다. 공개 호스팅에 올리는 것은 앱 코드와 레시피뿐입니다. 개인 백업 JSON은 절대로 공개 저장소에 올리지 마세요.

1. 기존 V3/V4에서 재고 메뉴 > 백업 파일 저장(JSON).
2. GitHub 등 정적 HTTPS 호스팅에서 새 사이트 생성. GitHub Pages 사용 시 공개 저장소를 만든 뒤 압축을 푼 index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, .nojekyll 을 루트에 업로드합니다.
3. Settings > Pages > Deploy from a branch > main / root > Save. 발급된 HTTPS 주소를 갤럭시 Chrome에서 접속합니다.
4. 오프라인 캐시 준비 완료를 확인하고 Chrome 메뉴 > 앱 설치 또는 홈 화면에 추가. 홈 화면 아이콘을 실행합니다.
5. 재고 > 백업 불러오기에서 V3/V4 JSON을 선택합니다. V5.1에서도 정기적으로 JSON 백업하세요.
6. 비행기 모드에서 앱을 재실행하고 식단/추천/식비가 열리는지 확인하세요. 브라우저 데이터 삭제 시 로컬 기록이 지워질 수 있습니다.
