1. 기존 앱의 더보기 → 백업 저장에서 JSON을 내려받아 개인 기기에 보관하세요.
2. 업데이트 ZIP을 압축 해제하세요. 압축 안의 파일, illustrations 폴더, fonts 폴더를 기존 recipe 저장소 main의 루트에 업로드하세요. 같은 이름의 파일을 교체하고 폴더 구조를 유지하세요.
   https://github.com/wnwjdgns1994-ship-it/recipe/upload/main
3. Commit changes 후 GitHub Actions에서 Pages 배포가 성공했는지 확인하세요.
   https://github.com/wnwjdgns1994-ship-it/recipe/actions
4. 인터넷이 연결된 상태에서 기존 앱 주소를 새로고침하고, 홈 화면 앱을 완전히 종료한 뒤 다시 실행하세요. 상단에 V10이 표시되면 식단과 즐겨찾기, 냉장고 기록을 확인하세요.
   https://wnwjdgns1994-ship-it.github.io/recipe/

기존 앱의 주소와 설치 식별자는 유지됩니다. 앱 삭제, 사이트 데이터 초기화, 개인 JSON의 공개 저장소 업로드는 피하세요.
이전 저장 기록이 있는 주차에서는 기존 식단을 유지합니다. 주간 식단에서 기본 식단 적용을 누르면 고정·조리 완료 메뉴를 유지한 채 기본 식단을 사용할 수 있습니다. 즐겨찾기에 넣은 예전 레시피는 레시피 → 즐겨찾기에서 열 수 있습니다.
주간 식단의 이번 주 구매 목록을 펼치면 사용 가능한 재고를 뺀 구매량을 볼 수 있습니다. 구매 체크는 하단 장보기 화면과 연동됩니다.
별도 오프라인 HTML은 브라우저로 열어 사용할 수 있습니다. 웹 앱 기록을 이어서 보려면 더보기 → 백업 복원에서 같은 JSON을 불러오세요.

공개 저장소에서 확보한 초기 버전은 V6.1입니다. 별도 V7 원본의 백업 호환성은 확인이 필요합니다.
음식 그림은 모두 유형별 참고 일러스트입니다. 일러스트와 한글 글꼴은 오프라인 버전에 포함되어 있습니다.
